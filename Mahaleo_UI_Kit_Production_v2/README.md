# Mahaleo — UI Kit de production

Kit de la deuxième proposition rétro, prêt à transmettre à Codex pour l'intégrer dans un projet e-commerce Next.js existant.

## Utilisation

1. Ouvrir `reference/index.html` pour consulter la maquette interactive.
2. Donner le dossier complet à Codex et coller `CODEX_PROMPT.md`.
3. Indiquer le chemin du projet cible.
4. Valider les données commerciales listées dans `specs/PRODUCTION_REQUIREMENTS.md`.

## Contenu

- `reference/` : maquette autonome et assets.
- `specs/` : design system, composants, responsive et exigences de production.
- `data/products.example.json` : contrat de données proposé.
- `CODEX_PROMPT.md` : prompt prêt à copier.
- `QA_CHECKLIST.md` : contrôles avant lancement.

Le logo `reference/assets/logo-mahaleo.png` est le logo rouge fourni et doit rester inchangé. Les vêtements et la guitare sont des visuels de direction artistique à remplacer par les assets validés de production. La photo `mahaleo-1972.jpg`, créditée à Lucien Rajaonina et issue de Mahaleo.com / Laterit, exige une autorisation d'exploitation commerciale.

Les noms, prix, tailles, stocks, matières, livraisons et retours de la maquette restent indicatifs.
